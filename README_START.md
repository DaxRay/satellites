# Запуск

Из папки проекта:

```powershell
python emulator_v2.py
```

Без эмулятора, для проверки заглушек: `python main.py`.

Редактируй main.py, сохраняй, нажимай «Проверить main.py».
Модем и гироскоп передаются в Antenna(modem, gyroscope),
приводы — через connect_drive(drive). Все соглашения и пример интеграции:
risley_v2/README_RU.md. Виртуальные приборы: risley_v2/virtual_devices.py.

3D-чертёж с углами: angles_3d.html (открывается в браузере).
Движение, качка, орбита и шум приборов меняются в окне стенда или config.py.
Предыдущие main.py и эмулятор сохранены в архиве перед установкой.

Поиск неблокирующий. real_time — простой исходный вариант сопровождения,
который можно улучшать в main.py; стенд оценивает его фактическую работу.
